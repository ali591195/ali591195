## Featured Work

- **[Aura: Pearls AQI Predictor](https://github.com/ali591195/aura-pearls-aqi-predictor)** — Serverless, end-to-end ML system forecasting 4-day-ahead AQI for Lahore. Each forecast horizon is served by an independently cross-validated model (XGBoost, Dense NN, LightGBM, Random Forest); Hopsworks feature store, GitHub Actions scheduling, FastAPI backend, React/Vite dashboard. [Live dashboard](https://aura-aqi.vercel.app) · [Live API](https://aura-pearls-aqi-predictor.fastapicloud.dev)
- **[Apollo: Solar Microgrid Agent](https://github.com/ali591195/apollo-rl-ems)** — PPO reinforcement learning agent (Stable-Baselines3) managing a custom-built solar/battery/demand microgrid environment. Beats rule-based and random baselines on reward and stability across two environment variants. [Model checkpoints](https://huggingface.co/ali591195/apollo-rl-ems)
- **[Fake News Detection](https://github.com/ali591195/fake-news-detection)** — Comparative study across 6 ML models, each matched to a feature representation suited to its assumptions. Final Random Forest model hits 0.992 F1, with custom-built (non-SHAP) interpretability. [Live demo](https://huggingface.co/spaces/ali591195/fake-news-detector)
